Viva Quick-Reference Cheat Sheet

1. What is MVC Architecture?
Model (Book POJO), View (HTML5/CSS3/JS UI), Controller (BookController REST API). Business logic resides in Service, and persistence resides in DAO.

2. JdbcTemplate vs Raw JDBC?
Raw JDBC requires manual driver loading, connection opening/closing, and catching SQLExceptions. Spring's JdbcTemplate eliminates boilerplate and translates SQLExceptions into unchecked Spring DataAccessExceptions.

3. Constructor Injection vs Field Injection?
Constructor injection (used across this project) ensures immutability (final fields) and safe unit testing. Field injection (@Autowired on fields) uses reflection directly.

4. What is AOP?
Aspect-Oriented Programming isolates cross-cutting concerns (logging, security) using Aspects, JoinPoints, Pointcuts, and Advices (@Before, @After).

5. Bean Lifecycle Callbacks?
@PostConstruct runs right after dependencies are injected; @PreDestroy runs right before container shuts down.
